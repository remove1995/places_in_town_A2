# What’s the place?

Готовая игра с 13 отзывами для угадывания мест в городе.

## Содержимое

- index.html — весь исходный код: HTML, CSS, JavaScript, тексты отзывов и SVG-иконки.
- assets/ — фотографии, аватарки, звуки flip.m4a и magic.m4a, лицензия иконок Lucide.
- originals/ — исходные звуковые файлы flip.MOV и magic.MOV.

## Публикация

Распакуйте ZIP и загрузите его содержимое в корень репозитория GitHub, сохраняя папку assets и названия файлов. Для GitHub Pages используйте этот корень как каталог публикации. Сборка и установка зависимостей не нужны.

## Локальный запуск

Из папки с index.html запустите:

```sh
python3 -m http.server 8000
```

Откройте http://localhost:8000. Звуки включаются после первого нажатия на карточку.

## Правки

Все настройки находятся в index.html. Массивы reviews и places содержат отзывы и ответы. Коэффициент gain.gain.value=0.5 устанавливает половину исходной громкости обоих звуков.

Имена и статистика авторов отзывов вымышлены. Лицензия используемых иконок находится в assets/lucide-license.txt.
